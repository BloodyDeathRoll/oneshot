# harvester / CHANGELOG.md — version history, one entry per approved diff.

- **0.4.0** — 2026-09-28 — Video. Shahar rejected a run because video the business published never reached the site: "Videos are much more engaging than images and whenever you find one you should use it!" New hard constraint 6: hunt video on every surface (own site incl. hero embeds, YouTube, Vimeo, public Instagram/Facebook reels), fetch it with the new `tools/fetch-video.mjs` (documented in `tools.md`), look at the contact sheets, cut the best 1–3 into hero renditions + poster, and record every video in `dossier.json` `videos[]` (`schemas/dossier.md` v0.2). A business that publishes video with an empty `videos[]` is an incomplete harvest. Same licence rule as images. Old constraints 6–11 are now 7–12, unchanged; the hand-off checklist gains a video check.
- **0.3.0** — 2026-09-20 — Runtime prompt is now assembled from `agents/wiring.json` by `node tools/prompt.mjs harvester`, and the `Runtime prompt =` line names every layer it really gets (`tools.md`, `evals.md`, `run.yaml` and the schemas were silently dropped before). `tools/check-wiring.mjs` fails the run if any layer is unreachable.
