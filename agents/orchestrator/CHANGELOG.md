# orchestrator / CHANGELOG.md — version history, one entry per approved diff.

- **0.2.1** — 2026-09-21 — Approved by Shahar in session. Hard constraint 3's existence check for `mocked` was "mockup dirs"; since designer 0.3.0 a 4e mockup is one HTML file with a look-log and per-round shots, so the check now names `dist/index.html`, the `look-log` in `notes.md` and `shots/round-N/` for all three variants.
- **0.2.0** — 2026-09-20 — Runtime prompt is now assembled from `agents/wiring.json` by `node tools/prompt.mjs orchestrator`, and the `Runtime prompt =` line names every layer it really gets (`tools.md`, `evals.md`, `run.yaml` and the schemas were silently dropped before). `tools/check-wiring.mjs` fails the run if any layer is unreachable.
- **0.2.2** — 2026-09-28 — From proposal 007 (approved by Shahar). Station 3b (auditor) in the order; `audited` requires `dossier/<slug>/audit.json`.
- **0.3.0** — 2026-09-28 — 4f/5 run three independent reviewers (critic + visual-critic + experience-critic); failing mockups loop back to the designer before the human gate (max 3 rounds); usage.jsonl per agent run.
- **0.3.1** — 2026-09-28 — The gate always shows three passing mockups: loop until all three pass; after round 5 ask the human. (Shahar: "I asked for 3 mockups" — 0.3.0 had dropped the two that failed after round 3.)
- **0.3.2** — 2026-10-02 — Approved by Shahar in session (two operators, docs/team.md). `mocked` no longer requires kept `shots/round-N/` folders (the look-log is the record); after every scored round run `tools/clean-shots.mjs`; every ledger line carries `operator`, and each station appends an `activity.jsonl` line.
- **0.4.0** — 2026-10-05 — Approved by Shahar in session (2026-10-05): "We build a demo to sell to a client. If we succeed and the client wants a CMS, THEN you implement a CMS. NOT BEFORE. Change the workflow to reflect that." New order: 6 Preview (`previewed`, static, no CMS) → 7 Pitch (`packaged`, gate c → `pitched` → `outcome:*`) → after `outcome:sale`, gate e: the client's product choice, a human `product_chosen` line with `hosting_mode` → 8 Deliver (`delivered`; self-hosted then `handoff_verified → access_revoked`). Existence checks per new state; gate prompt gains gate e. Also fixes the header, which still read 0.3.1 after the 0.3.2 entry above (the run pinned 0.3.2).
