# dashboard/data.json — every field and its source

Generated by `node dashboard/data.mjs` (BRIEF.md §2). Nothing in the file is typed by hand; each
field below names the disk source it is derived from. `tools/dashboard.mjs` imports the same
`buildData()` to render the earlier register page.

Sources: **L** = `ledger.jsonl` (docs/ledger.md), **R** = `run.yaml`, **D** = `dossier/<slug>/dossier.json`,
**S** = `sites/<slug>/` (deploy.json, pitch/, final/shots/), **C** = `agents/*/CHANGELOG.md`,
**P** = `proposals/<run>/*.md`, **E** = `expenses.jsonl` (docs/expenses.md; absent today),
**K** = constants in `data.mjs` (pipeline order, stations, next-step table — from PLAN.md §4 and concepts.md).

## What is NOT in the file, on purpose

- Token spend per business or per run: not recorded anywhere (`totals.token_spend_tracked: false`).
- Any cost: `expenses.jsonl` does not exist yet.
- Pitch channel: no field in the ledger schema.
- Sparklines for pitched / replies / clients: no first value yet (`empty_states.sparkline`).
