## conflicts

1. **Booking page shape.** concepts.md §3.2 asks for `/book/` plus one page per level; this station's brief asked for one `book/index.html`. Built one page with the level chosen at the top (radio cards; `?level=` and `?room=` preselect from the home page). The form's action follows the chosen level. Cost of the alternative: three near-identical pages.
2. **Booking colour.** concepts.md gives `#B84F50` (4.92:1). It reads as a dusty brick next to the pool blue, which house rule 4 / custom.md ("clean, saturated") warn against. Used `#C8463C` (white text 4.78:1, AA). Revert is one token.
3. **Tint.** concepts.md `#EBECEE`; used `#EEF0F2` (a step lighter, still cool) so alternating sections don't read grey. Script-title teal `#00718F` is 4.89:1 on it.
4. **Closing band.** Concept: `closing` line in white over img-093. White text over the busy dusk photo failed legibility at both widths; the line and buttons sit in a white rounded card on the photo instead (proposal 002 allows rounded, gentle shadows).
5. **Funnel primary class.** audit.json `recommended.primary_action` = engine; `funnel.mjs` reports whatsapp because it doesn't recognise the booking page's GET form to the engine. Every booking CTA leads to the engine via `book/` (verified above). Not changed: linking cards straight to Bookinglayer would skip the booking pages Shahar asked for. Tool gap to raise.
6. **Hero still vs motion.** vid-009e contains a ~0.3 s dissolve from the pool to the reef; headless captures at ~2.7 s land on it and look like a double exposure. It's the owner's edit, not an effect of ours; if the critics object, the fix is a re-cut with a hard cut (fetch-video), not a page change.
7. **check-design on sub-pages.** The tool serves a single page's own folder, so `book/index.html` can't load `../` assets; checked through a temp root copy. Tool gap to raise.
