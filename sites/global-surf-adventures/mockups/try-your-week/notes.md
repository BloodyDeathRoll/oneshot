Old-site screenshots compared every round: `dossier/.../assets/old-site-home-desktop*.png`, `old-site-lodge-*`.

## gaps

- **Instagram feed:** no post was harvested; the section shows the lodge's own photographs as tiles linking to
  @globalsurf_kabalana, with no post chrome. Live feed needs a build-time fetch with the owner's token (schema gap).
- **WhatsApp:** only the Israeli HQ number exists; every WhatsApp button uses the copy's `bookingLinks` URL
  exactly (one prefill text for all, incl. Freestylers "Ask about dates").
- **Prices beyond 7 nights:** the snapshot has only the 7-night base; for 14/21/28 nights the totals show "–"
  until the live quote returns (JS off / API down: "–", engine prices it). Twin "sharing" supplement ($80.025)
  was sampled for a couple and is applied to any party of 2+.
- **Choosable Saturdays** in the snapshot are the 1-guest list; other guest mixes are corrected live.
- **Room photo → room type mapping** is the copywriter's; owner to confirm (docs/bookinglayer.md §6.3 #4).
- **Season:** none in the dossier; not shown.
- JS off: the nights control submits `duration` in days (8/15/22/29) because a GET form cannot compute `end`;
  docs/bookinglayer.md only tested `duration=7` (read as days, then corrected). Untested — JS path uses `end`.
- Fonts come from Google Fonts at 4e (≈ 200 KB, over the 150 KB line); 4g self-hosts and subsets. Italic
  axis dropped to save 63 KB.

## conflicts

- **Hero subtitle:** concept says "Surf weeks in Kabalana, Sri Lanka"; that line is not in the copy. Used the
  copy's `mockup_extras.hero.subtitle` "All levels, steps from the beach" (also Shahar's example).
- **Level CTA:** concept "Book Level 1"; copy `ctas.level_1` "Choose Level 1" — used the copy.
- **Duplicate photo:** img-078 is the same frame as img-063 (Booking.com copy of the site photo); dropped from
  the dorm slideshow rather than show one picture twice. Copy's gallery list otherwise unchanged.
- **Plural:** copy `total_all` "Total for {n} guests" is rendered "Total for 1 guest" when n = 1 (template logic).
- **"Saturday check-in"** appended to the copy's price line on the home info row (both strings are copy).
- **First-screen booking action vs calibration:** per concept and calibration the hero carries one CTA,
  "Choose your level", which scrolls to the level stage; the header "Book now" appears after the hero. Playbook
  §0/§3 want a booking action and a proof point on the first screen; `funnel.mjs` therefore reports
  `cta_above_fold: false` and no rating is in the hero (calibration: "No rating in the hero"). Alternative: point
  the hero button at `book/` — cost: skips the stage that is this concept's one idea.
- **custom.md** (geometric sans, no serifs, thin black lines, no rounded cards, no shadows) is overridden by
  Shahar's gate feedback per proposal 002: Newsreader + Mansalva script titles, no lines, 10 px rounded buttons,
  16 px rounded media, soft shadows only on floating controls (hero button, slideshow arrows, stepper buttons, calendar popover, bottom bars).
- **dossier.videos** has no record for vid-003e / vid-002e cuts nor for vid-010c (made here) — orchestrator/
  harvester should record them before 4g.
