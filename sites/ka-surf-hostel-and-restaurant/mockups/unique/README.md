# templates/unique/ — Astro template for the "unique" variant

The full-blown variant: a canvas layer behind the hero (animated grain and a slowwater-like ripple,
no WebGL dependency), overlapping kinetic type, an asymmetric editorial grid with full-bleed
figures, and the booking drawer. Same content contract as the other two.
Canvas is skipped entirely under `prefers-reduced-motion`, and the page is fully readable without JS.
