## conflicts

1. **custom.md "grounds are clean whites and light neutrals" vs the client's brief** (A6/A16: dark, heavily black and white, one gold). Built dark, per Shahar's override and the concept; house rule 1 (light themes) is surf-only and this run is `brand_design`, so `check-design` does not apply it. Not blocking.
2. **custom.md "on the first screen only the header, a short title and one CTA"** vs the brief's hero (eyebrow + headline + subtitle + two doors + film). Kept eyebrow + headline + the two doors as one segmented control + a small "הסרט" button; the subtitle opens the next phase (concept §4.3). The Check is in the header and the phone bar. Not blocking.
3. **Hero media is drawn, not the footage** (base.md: video first). The first screen is the WebGL glare with vid-036's profile frame in its pool; the footage arrives at the first scroll step when the beam lands. The concept gives the reason (the glare is the brand idea); the critics should judge it. Not blocking.
4. **JavaScript renders the page** (hash routes from the inlined copy). With JS off only the `<noscript>` contact line shows (`audit: noJS links 0`). At 4g this is an Astro static build and every route is static HTML. Not blocking at 4e (playbook §4's "core content in the HTML" is 4g's), but a critic running no-JS will see it.
5. **Primary action:** `audit.json.recommended.primary_action` is WhatsApp; the brief makes the Check the hero action. Gold Check in the header and the phone bar, WhatsApp one tap away in the bar (phone) and the docked chip (desktop) on every route. Not blocking.
6. **Headless WebGL:** under `shoot.mjs`'s SwiftShader the context was lost in early rounds; since round 3 it renders. If a critic's run loses it, the page shows the CSS beam (designed, phase-aware), not a blank. Not blocking.
7. **Process:** the first-screen rounds were not done before building the rest (see the look-log note). Not blocking; recorded.
8. `tools/check-design.mjs talouloren` also wrote `shots/check-design/` into `calm/` and `interactive/` (it shoots every variant of the slug). Scratch, gitignored; not touched otherwise.
