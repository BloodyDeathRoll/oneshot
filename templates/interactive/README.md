# templates/interactive/ — Astro template for the "interactive" variant

Same content contract as calm (`schemas/site-content.md` v0.2), more movement: a parallax hero,
scroll-revealed sections, a horizontal photo rail you can drag, sticky section headers and a
booking drawer. No WebGL — motion is CSS and a few lines of JS, inside the playbook §4 budget.
All motion is disabled under `prefers-reduced-motion`.
